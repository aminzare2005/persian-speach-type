# Brand — Persian Speach Type

## Identity
- **Name:** Persian Speach Type
- **Spelling:** *speach* (intentional; matches project folder)
- **Promise:** هر جا تایپ می‌کنی، فقط حرف بزن.

## Voice
- کوتاه، مستقیم، محترمانه
- بدون اغراق بازاری
- فارسی معیار با نیم‌فاصله درست

## Visual
- Glass dark capsule floating above the taskbar
- Teal primary `#0D9488` / bright `#2DD4BF`
- Accent orange `#EA580C` (sparingly)
- Typeface: Arad (local FarsiDigits; bundled in `src/assets/fonts/arad/`)
- Icons: Phosphor (outline/regular; fill only for primary mic)

## Anti-patterns
- No purple gradients
- No emoji icons
- No cluttered first surface — pill + one sheet max
